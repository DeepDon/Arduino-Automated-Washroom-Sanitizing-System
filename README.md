# Arduino-Based Automated Washroom Sanitizing and Monitoring System

An automated, IoT-enabled public washroom sanitization, air quality monitoring, and COVID-19 statistics tracking system[cite: 44, 47, 50]. Designed to eliminate unhygienic conditions in public restrooms, reduce human contact with hazardous environments, and automate floor cleaning, handwashing, and ventilation alerts[cite: 43, 44, 50].
